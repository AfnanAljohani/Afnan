# AI Trainees Hub | منصة متدربي الذكاء الاصطناعي

نسخة من واجهة الموقع المنشور على Manus:
https://aitrainees-skyqjck5.manus.space/

## المحتوى
- `index.html` — الصفحة الرئيسية (بعد حذف سكربتات Manus: محرر المساحة، التحليلات، وأداة التقاط الأخطاء).
- `404.html` — نسخة من الصفحة الرئيسية حتى تعمل روابط الصفحات الداخلية على GitHub Pages.
- `assets/` — ملفات JavaScript و CSS المبنية (minified).

## ملاحظة مهمة
هذه **الواجهة فقط**. التطبيق الأصلي يعتمد على خادم (`/api/trpc`) لتسجيل الدخول بـ OTP،
الحضور بالـ QR، المهام، الإشعارات ولوحة الإدارة. هذه الميزات لن تعمل خارج Manus
إلا بعد تصدير الكود المصدري الكامل (الخادم + قاعدة البيانات) من Manus.

## التشغيل محلياً
```bash
cd ai-trainees-hub
python3 -m http.server 8000
# افتح http://localhost:8000
```
