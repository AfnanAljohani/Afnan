# EWA Safety Club · نادي السلامة

موقع نادي السلامة: برومو متحرك لإرشادات السلامة، حوار سليم EWA وسلامة EWA بالعربي والإنجليزي، ونتائج جولة التشييك.

افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع.

## مسار الإنجليزية · English Path

موقع عائلي لتعلّم الإنجليزية بالمهارات الأربع (قراءة، استماع، تحدّث، كتابة) من A1 حتى C2، بالعربي والإنجليزي:
المستويات، دليل كل مهارة، أفضل التطبيقات (Duolingo، Cambly، ELSA…)، أقسام فهد ومشاعل وأفنان وخالد وميساء ومحمد
مع مهمات يومية من 13 أكتوبر 2026 حتى 13 يناير 2027، وقاموس مصطلحات الذكاء الاصطناعي لقسم أفنان.

افتح `english/index.html` في المتصفح.

## مختبر AIF-C01 · AWS AI Practitioner

موقع مذاكرة لاختبار AWS Certified AI Practitioner (AIF-C01 الإصدار 1.1) بالعربي والإنجليزي: عد تنازلي لـ ٢٥ نوفمبر، خطة ٢٢ يوم،
بطاقات الخدمات حسب مجموعات التشابه، جداول مقارنة تفاعلية، ٤٠٧ سؤال سيناريو بالعربي والإنجليزي مقسمة لمجموعات حسب المجال مع شرح كل خيار، اختبار تجريبي ٦٥ سؤال بدرجة من ١٠٠٠،
بطاقات تكرار متباعد، الكلمات المفتاحية، وفيديوهات يوتيوب ومصادر رسمية.

افتح `aws-ai/index.html` في المتصفح. لإضافة أسئلة عدّل مصفوفة `QUESTIONS` أو `BANK` (صف واحد لكل سؤال بالعربي والإنجليزي).
